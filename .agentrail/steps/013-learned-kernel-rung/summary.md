Rung 6 of demos/cnn is built and runnable: a convolution kernel recovered from examples by gradient descent, using grad through windows and the broadcast multiply with adam. It deliberately runs the same training twice. On a linear ramp the loss reaches 3.9e-19 while the learned kernel is still wrong by 1.13, because neighbouring receptive fields are linearly dependent and the recovery is underdetermined; on random input the fields are independent and the teacher kernel comes back to about 1.9e-9. The lesson is that low loss is evidence about the data fitted, not proof of recovering the function behind it. The demo states that training is not part of Equation (1).
