Initialized gguf-inspection and implemented a conservative bounded little-endian GGUF v3 catalog foundation against the official ggml specification. MLPL parses magic/version/counts, required architecture and alignment metadata, zero/one F32 tensor descriptor, padding, shape/offset/file bounds using exact bounded reads without payload materialization. Added generated valid and adversarial fixtures, deterministic tests, a runnable default-gate demo, and budget/attribution/complexity documentation.
